# Music catalogue

Everything Sonder can play lives in one place, and every record describes the
file it points at. This is the rule the whole system rests on:

> **What the interface shows is what comes out of the speakers.**
> A track's title, artist and duration belong to the audio at its `audioUrl`.
> Nothing else is acceptable.

---

## 1. Where audio files go

```
public/audio/
  drift.mp3
  rainfall-window.mp3
  neon-rain.mp3
  …
```

Vite serves `public/` at the site root, so a file at `public/audio/drift.mp3`
is reachable at `/audio/drift.mp3` in both dev and the production build.

**Local files are the recommended path.** They cannot 404, cannot be blocked by
CORS, need no third-party service to stay online, and load instantly.

External URLs are supported (`source: 'external'`) but come with real
constraints — see [§8](#8-external-urls).

## 2. How to add a track

Two steps.

**Step one** — put the MP3 in `public/audio/`.

**Step two** — add a record to `src/data/music/tracks.ts`:

```ts
local({
  id: 'midnight-rain',
  title: 'Midnight Rain',
  artist: 'Alex Rivers',
  album: 'Small Hours',
  audioUrl: '/audio/midnight-rain.mp3',
  duration: 214,                       // real seconds — see §3
  genre: 'Lo-fi',
  genres: ['Lo-fi', 'Ambient'],
  moods: ['melancholic', 'calm'],
  activities: ['studying', 'reading'],
  feelings: ['comfort', 'focus'],
  energy: 26,                          // 0–100
  valence: 34,                         // 0–100
  weather: ['rain'],
  timeOfDay: ['night'],
  tags: ['rain', 'tape', 'wordless'],
  description: 'Weather that gives you permission to cancel something.',
  hue: '#5C7CFA',
})
```

The `local()` helper stamps on `source`, `sourceId` and the licence fields that
every shipped track shares, so a record only carries what is distinct about it.
For a track under a different licence, write the full object instead.

Nothing else needs touching. Artists, genre lists, search, recommendations and
the mood pages are all derived from `tracks.ts` at import time.

## 3. Required metadata

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Unique. Convention is the audio filename without extension. |
| `title` / `artist` | yes | Must describe the actual recording. |
| `audioUrl` | yes | `/audio/…` for local, absolute URL for external. |
| `duration` | yes | **Real seconds.** See below. |
| `moods` | yes | At least one, from the `Mood` union. |
| `activities` / `feelings` | yes | From their unions. Empty arrays are allowed but hurt recommendations. |
| `energy` / `valence` | yes | 0–100 integers. |
| `genres` | yes | Free strings; they become the genre filter automatically. |
| `hue` | yes | Hex. The accent the interface paints itself with for this track. |
| `weather` / `timeOfDay` | no | Strong signals when present. |
| `tags` / `description` | no | Tags are searchable; the description shows nowhere yet but is used by the catalogue tooling. |
| `album` / `albumArt` | no | Without `albumArt` a generated sleeve is used — see [§9](#9-artwork). |
| `license` / `licenseUrl` | yes in practice | The validator warns without one. |

### Duration must be real

`duration` is what the track list and playlist runtimes display before any
audio loads, and the player corrects itself from `audio.duration` the moment
metadata arrives. If the two disagree, the interface lies for a second.

The generator keeps them in sync automatically:

```bash
python tools/generate-demo-audio.py --sync-only
```

That reads the real decoded length of every file in `public/audio/` and rewrites
`duration` in `tracks.ts` to match. Run it after adding or replacing audio.

If you add a track by hand and do not know the length, read it once in the
browser console:

```js
const a = new Audio('/audio/your-track.mp3')
a.addEventListener('loadedmetadata', () => console.log(a.duration))
```

## 4. How licensing works

Every track carries its own licence. The rule is simple:

> **Do not add a track unless you have the right to play it in this app.**

That means one of:

- **Public domain / CC0** — no obligations.
- **Creative Commons with attribution** (CC BY, CC BY-SA…) — you must display
  the credit. Fill in `attribution` and `attributionUrl`.
- **Royalty-free with a licence you hold** — record the licence name and keep
  your receipt outside the repository.
- **Music you made** — you decide the terms.

Commercial recordings are **not** in that list. Do not add a Frank Ocean track
and point it at something else; do not add one and point it at a real Frank
Ocean file you do not have the rights to distribute.

### What ships today

All 24 tracks in `public/audio/` are **original instrumental music generated by
`tools/generate-demo-audio.py`**, released under CC0. The repository therefore
carries no third-party audio and no licence to honour. The artist names are the
project's own aliases for that generated output — they are not real performers,
and the catalogue does not claim they are.

Regenerate or extend them with:

```bash
pip install numpy lameenc
python tools/generate-demo-audio.py          # render all 24 + sync durations
python tools/generate-demo-audio.py --sync-only
```

Replacing them with your own licensed music is the expected path to production:
drop your MP3s in `public/audio/`, rewrite `tracks.ts`, and delete the
generator if you no longer need it.

## 5. How attribution is stored

Four optional fields on every track:

```ts
license: 'CC BY 4.0',
licenseUrl: 'https://creativecommons.org/licenses/by/4.0/',
attribution: 'Midnight Rain by Alex Rivers',
attributionUrl: 'https://example.com/alex-rivers',
```

Read them through the helper rather than by hand, so every surface credits a
track the same way:

```ts
import { getTrackAttribution, catalogLicenses } from '@/services/music'

getTrackAttribution(track)
// { text: 'Midnight Rain by Alex Rivers (CC BY 4.0)',
//   license, licenseUrl, url, sourceName }

catalogLicenses()
// [{ license: 'CC0 1.0', licenseUrl: '…', count: 24 }]
```

`catalogLicenses()` is what a credits screen should be built from — it groups
the whole catalogue by licence.

## 6. How to test a track

1. `npm run dev`, then open the console. The catalogue validator runs on boot in
   development and prints either `[catalog] 24 tracks, 8 artists, no issues` or a
   grouped list of problems.
2. Search for the track by title in the app (⌘K) and play it.
3. Confirm the transport's total time matches the row's time. If they differ,
   `duration` is wrong — run `--sync-only`.
4. Confirm the audio you hear is the track named in the player.

To run the validator yourself:

```ts
import { validateMusicCatalog } from '@/services/music'
validateMusicCatalog() // CatalogIssue[]
```

It checks for missing ids, titles, artists and audio URLs; duplicate ids; two
tracks sharing one file; non-positive or implausible durations; unknown moods,
feelings, activities, weather or times; energy/valence outside 0–100; unknown
source ids; placeholder URLs; and missing licence metadata.

## 7. How recommendation scoring works

`src/services/music/recommendation.ts`. Every track in the catalogue is scored
against the intent and the playlist is the top of that ranking — never a
shuffle, and the same request always produces the same result.

| Signal | Weight |
| --- | --- |
| Mood overlap | 25 |
| Activity overlap | 20 |
| Artist named explicitly | 18 |
| Energy proximity | 16 |
| Feeling overlap | 15 |
| Valence proximity | 12 |
| Genre overlap | 10 |
| Weather match | 10 |
| Time-of-day match | 10 |
| Tag match | 5 |
| **Explicitly ruled out** | **−30** |

Overlaps are proportional (`shared / min(len)`), so matching one of one mood
scores higher than matching one of four. Proximity is `(1 − |a−b| / 100) ×
weight`, so an exact energy match earns the full 16 and a 100-point miss earns
nothing.

After ranking, two passes shape the result:

- **Diversity** — at most three tracks per artist.
- **Sequencing** — the list is ordered so it travels from where you are toward
  the energy you asked for, keeping the strongest match as the opener.

Reading a sentence into an intent happens in `intent.ts`, which is deliberately
about *feeling* rather than keywords. Phrases map to clusters, and a negation
pass handles the "but not…" half:

> *"I feel sad but I don't want depressing music"*
> → moods `[melancholic, lonely]`, avoid `[dark]`, valence target lifted to 54

Without that pass the request would return the most crushing tracks available,
which is the opposite of what was asked for.

## 8. External URLs

```ts
{
  source: 'external',
  sourceId: 'my-provider',
  audioUrl: 'https://cdn.example.com/track.mp3',
}
```

Register the provider in `src/services/music/sources.ts` first. Then be aware:

- **CORS** — the host must serve the file with permissive headers, or the
  browser will refuse it. There is no workaround that respects the source's
  terms; if a host does not allow direct playback, do not use it.
- **Availability** — an external host going down takes your catalogue with it.
- **A page is not a file.** A URL that renders a player in a browser is a web
  page. `audioUrl` must be the media file itself.
- **Never invent one.** A URL that has not been loaded successfully is not a
  source. `checkPlayable()` rejects blanks and obvious placeholders, but it
  cannot tell whether a plausible-looking URL is real.

When both a local and an external copy exist, prefer local.

## 9. Artwork

`albumArt` is optional. Without it, the track gets a **generated sleeve** —
a deterministic gradient field, one circular form and a row of signal bars,
seeded off the track id. It always belongs to its track and never changes
between reloads, which is why an unillustrated catalogue still looks like one
label's output rather than a pile of missing images.

If you set `albumArt`, it must be that track's actual artwork. Unrelated
imagery attached to a track is the same failure as unrelated audio.

## 10. Why commercial songs must not be added

Attaching a well-known title to audio you have not licensed fails twice:

1. **It is dishonest.** The interface claims to play a specific recording. If it
   plays something else, every duration, every artist credit and every "now
   playing" line is false.
2. **It is unlawful.** Distributing a commercial recording without a licence is
   infringement, and hosting one in `public/` distributes it to every visitor.

If you want the real thing, license it — through a provider whose terms permit
in-app playback — and add it as a normal catalogue record with its real
metadata. The architecture is ready for that: register a source, add the tracks,
and nothing else in the app has to change.
